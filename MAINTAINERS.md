## Responsibilities

Maintainers review pull requests, guard the normative documents, triage
security reports, and cut releases. New maintainers are added by consensus of
the existing maintainers after sustained, high-quality contributions.

## Contact

Use GitHub issues for anything public. Security reports follow
[SECURITY.md](SECURITY.md). Code of conduct reports go to the project lead
listed above.
