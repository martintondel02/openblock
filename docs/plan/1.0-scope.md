# OpenBlock 1.0.0 scope and delivery plan

> Status: active delivery plan · Last updated: 2026-11-25
> Depends on: [Roadmap](00-roadmap.md), [Milestones](01-milestones.md), [Decisions](../decisions.md)
>
> This document defines what "1.0.0" means for this project. It is updated as
> waves land and is the checklist the 1.0.0 and 1.0.1 audits use. It is deliberately
smaller than full Minecraft parity: 1.0.0 is a polished, self-hostable voxel
sandbox with the core survival loop, mobs, sound, and working multiplayer. The
Tier-2 feature track (dimensions, redstone, WASM mods, controllers, QUIC/TLS) is
post-1.0.

## 1.0.0 feature checklist

### World
- [x] Infinite deterministic terrain: 5 biomes (existing), blended heights,
      trees/features (existing), **caves and ravines**, **ore veins** (coal,
      iron, copper), surface cave entrances, no missing chunks at the edge of
      the render distance.
- [x] Day/night cycle with sky, sun/moon/stars, fog (existing).
- [ ] Weather? _Deferred post-1.0_ (documented).

### Survival loop
- [x] Health/hunger, fall damage, starvation, regeneration, death/respawn
      (existing v0.0.7).
- [x] Mining with tool requirements/speeds and durability; block drops as item
      entities with a 3 m pickup magnet (existing v0.0.8/0.0.9).
- [~] **Crafting**: 1.0 ships the recipe-book crafting UI (25 recipes, table
      gating, availability/ingredient feedback) instead of a spatial grid; a
      3x3 shaped grid is post-1.0. No torches/stairs/glass in 1.0 (`torches &
      light` are post-1.0; darkness/mob spawning uses time-of-day and depth).
- [x] **Smelting**: furnace block + fuel + smelt recipes; charcoal/coal, iron
      ingots, cooked food (glass deferred with the glass block).
- [x] **Ore progression**: stone tools -> coal -> furnace -> iron tools and
      armor; tool/armor durability, armor damage reduction.
- [x] **Food loop (simplified)**: apples (existing), raw/cooked beef and
      porkchop from animals, furnace cooking; hunger tuned so the loop is
      playable. Farming/crops are post-1.0.
- [x] **Mobs**: cows/pigs/sheep/chickens (wander/flee) and zombies (night/depth
      spawning, chase/attack, sun burn, despawn), drops, player attack and
      damage/knockback; no breeding/villagers/projectiles in 1.0.
- [x] **Chests** for storage (server-authoritative contents; UI).
- [~] Torches/block-light are **post-1.0**; 1.0 mob spawning uses time-of-day
      and depth (documented simplified darkness model).

### Multiplayer
- [x] `ob_protocol` v2 message catalog + JSON/TCP framing (interim transport;
      QUIC/TLS post-1.0) and handshake/content hash checks.
- [x] Dedicated `openblock-server` binary: world load/create, listen, config,
      console commands, chat, whitelist/max players, autosave, graceful stop.
- [x] Client connect flow: `--connect HOST:PORT` with connect/loading/failure
      screens; a full title screen / server browser is scheduled for 0.2.0.
- [x] World replication: chunk streaming with interest radius, block edits
      broadcast + remesh, player avatars, chat overlay, roster, server status/
      disconnect reasons. Name tags over avatars polish in 0.2.0.
- [x] Server-authoritative survival: inventories/vitals/equipment/actions/
      containers/mobs/items validated and replicated; player movement stays
      client-side in 1.0 (documented limitation, anti-cheat post-1.0).
- [x] Save/load multiplayer world + reconnect by name; multi-client loopback
      tests cover join/edits/loot/mobs/containers/death; LAN manual demo run.

### Audio
- [x] Procedural sound engine (runtime PulseAudio on Linux, silent stub
      elsewhere — no ALSA/cpal build deps) with material footsteps,
      break/place, hurt/death, eat/craft/pickup, tool break, UI and ambient
      wind/music loops; volumes and mute in settings; graceful no-device fallback.

### UI/UX
- [ ] Title screen: Continue, New world, Load world, Multiplayer (direct
      connect), Settings, Quit; world seed/name input. **Scheduled 0.2.0.**
- [ ] Pause/settings screen (existing) with Audio tab, controls rebinding for
      movement/actions, UI scale option, render distance/FOV/sensitivity.
- [x] HUD: hearts/hunger/armor, crosshair, hotbar, hurt feedback, chat, player
      roster, toasts, F3 overlay with multiplayer/network stats, day/night and
      mob counts. Breath/boss bars are post-1.0.
- [x] Inventory/crafting/furnace/chest screens: readable spacing, click-to-cursor
      item movement, tooltips/info lines, durability bars, armor slots, remote
      server-authoritative container windows.
- [ ] Accessibility: remappable keys, UI scale, reduced motion/head-bob toggle,
      colour-blind-safe critical cues. **Scheduled 0.2.0.**
- [ ] Localization? _Post-1.0_ (documented), English only for 1.0.

### Persistence / server ops
- [x] Save v4 plus sidecars covering mobs (`mobs.txt`), block entities
      (`block_entities.txt`), equipment, items and network players; automatic
      migration from v1-v4; crash-safe atomic writes; backup/restore scripts and
      docs (server-side backup command remains a CLI/script workflow in 1.0).
- [x] Dedicated server packaging: hardened systemd unit/sysusers/tmpfiles,
      dependency-free multi-stage container image + compose, admin handbook
      (quickstart/config/administration/security/backup/upgrade/troubleshooting),
      firewalld config, load-test bots and dependency check.
- [x] Client packaging: Flatpak + COPR RPM manifests updated for 0.1.0 (final
      1.0 version/notes in the release wave); desktop entry/metainfo maintained.

### Quality gates for 1.0.0
- [x] `cargo test --workspace`, clippy `-D warnings`, fmt, rustdoc,
      architecture/docs checks green on Linux/Fedora/Windows/macOS CI (ignored
      GPU/measurement probes remain intentionally ignored).
- [x] Deterministic smoke/hash tests; save migration tests; protocol
      malformed/oversized/fuzz-ish and adversarial tests (security wave).
- [x] Performance: offscreen render benchmark gate holds; single-player/server
      simulation benchmarks published (worldgen 0.92 ms/chunk, tick p99
      <=0.03 ms baseline, save 21-156 ms depending on size); 8-player network
      load harness exists but the automated 8-player tick/p99 gate is scheduled
      for the 0.9.0 hardening wave.
- [ ] No bundled third-party assets; resource packs loaded locally only.
- [x] Docs: README feature list/screenshots/controls, CHANGELOG, packaging and
      admin docs, protocol/server specs, known limitations (final 1.0 polish in
      the release wave).

## Version wave plan (each wave ends in a tagged release + green CI)

| Version | Contents |
| --- | --- |
| 0.1.0 | Delivered: protocol v2 + dedicated server; client connect with replication/avatars; server-authoritative survival + containers + entity replication; audio; caves/ravines/ores; mobs/combat; packaging/ops; benchmarks. |
| 0.2.0 | Title screen / world select / direct-connect UI, controls rebinding, UI scale/accessibility, name tags and multiplayer UI polish; crafting-grid design decision (1.0 ships recipe-book). |
| 0.3.0 | Ores + furnace/smelting/iron tools; crafting grid + furnace UI; torch light; new blocks/textures. |
| 0.4.0 | Mobs & combat (passive + hostile, AI, drops, attack, damage/knockback) with server-side entities and rendering. |
| 0.5.0 | Farming/food variety, armor, chests, hunger balancing; multiplayer mob/item replication hardening. |
| 0.6.0 | Title screen/world select/connect UI, controls rebinding, UI scale, HUD/chat polish; persistence maturity (mobs/chests/crops/furnaces, migration tests, backups). |
| 0.7.0 | Server ops (config/commands/whitelist/backups/systemd/container), packaging (Flatpak/COPR), load/soak tests and docs. |
| 0.8.0 | Performance pass, accessibility, bug bash, documentation/spec alignment, screenshots. |
| 0.9.0 | Release candidate hardening: fuzz/protocol/save abuse, soak, security review, final fixes. |
| 1.0.0 | Release: README/CHANGELOG/measurements, screenshots, packaging, release notes. |
| 1.0.1 | Strict audit findings fixed: playtest bugs, UX polish, performance/docs/security issues found in the 1.0.0 review. |

## Non-goals for 1.0.0 (documented as post-1.0)
Nether/End and other dimensions, redstone, WASM mods, controller support,
localization, full Minecraft parity block/item counts, QUIC/TLS anti-cheat
infrastructure, mobile/web, shader packs beyond the built-in visual options.

## Open questions

- How much server-authoritative movement/anti-cheat is required for 1.0.0
  versus documented as a 1.0 limitation? Current plan: client-side movement in
  1.0, server validation of edits and entity simulation, anti-cheat post-1.0.
- Torches/block-lighting versus the simplified "time-of-day + depth" darkness
  model: if full light propagation does not fit the 1.0 wave plan it is marked
  post-1.0 and mob spawning uses the simplified model.
- Farming/crops were descoped from the 1.0.0 checklist; food comes from apples,
  animals and cooking. Revisit if the 0.5.0 wave has slack.
- Whether the interactive title-screen server browser is required for 1.0.0 or
  direct-connect input plus recent servers is sufficient (current plan: direct
  connect + recent list).
